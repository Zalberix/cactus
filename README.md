# 🌵Cactus
>🚧 Находится в стадии разработки

Cactus - сервис рассылки уведомлений (почта, telegram, push), с пользовательским интерфейсом и API

Для первого запуска выполнить команду make, запустится docker-compose, запустится миграция (dbmate, есть schema.sql если утилиты нет по пути db/schema.sql), запустятся сиды для demo, запустятся основное приложение и 1 воркер для email.
```
make
```
Для проверки работы почты развернут сервер MTA на порту 127.0.0.1:8025

Основной API для работы с сервисом
POST http://localhost:8080/api/email/send где email это тип рассылки. curl запрос представлен в файле /docs/api.send.curl, с учетом того что нужно поменять путь до файла если хотите его прикрепить.

Для отслеживания состояния pipeline сообщения можно подписаться на состояние сообщения.
ws://localhost:8080/ws/pipeline/374ebd1b-4303-4588-97e5-0af672fc08ca где в конце представлен uuid сообщения. (PS сообщение проходит очень быстро, для симуляции нужно поставить задержку менжу отправкой статусов в файле cmd/email-worker/worker.go:324 )

Если у вас уже есть база данных то можно просто запускать make run
```
make run
```

В случае изменения базы данных нужно удалить все таблицы и запустить команду make.
